# Voice Agent

A production-style voice agent built on [LiveKit Agents](https://docs.livekit.io/agents/), Sarvam AI (STT/TTS), and OpenAI (LLM).

## Setup

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # fill in your credentials
```
